# Werkplaats 0.36.21

Deze versie helpt je de download goed uit te pakken en in de juiste browser te openen. Als je alleen Begin hier.html uit de ZIP opent, vertelt die pagina hoe je het hele pakket uitpakt en waar je daarna begint.

Gebruik op Windows **Alles uitpakken** bij de ZIP. Dubbelklik op de Mac in Finder op de ZIP en kies in de uitgepakte map **Control-klik → Open met → Google Chrome** bij Begin hier.html. Microsoft Edge kan ook. Laat Bestanden naast Begin hier.html staan. De optionele snelkoppeling voor het Mac Dock is voor de workshop overbodig.

START-HIER.txt helpt je ook bij het kiezen van een werkmap, het bewaren van je eerste notitie en het aanpassen van Werkplaats aan je eigen wensen.
